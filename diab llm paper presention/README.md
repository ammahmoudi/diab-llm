## Notes

- The Chronos and Time-LLM PDFs are official arXiv versions.
- The published DiabLLM PDF is closed access and the IEEE endpoint blocks automated retrieval. `diabllm.pdf` is therefore an author-manuscript rendering generated from the repository's `diab-llm-article/` LaTeX source.
- Markdown files were extracted automatically from the corresponding PDFs. Equations, tables, figures, and multi-column reading order may require manual cleanup before presentation use.
